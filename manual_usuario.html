Descripción General del Sistema

El Sistema de Análisis Meteorológico es una plataforma web profesional diseñada para la gestión, visualización y análisis de datos meteorológicos provenientes de la Red GEAA de estaciones meteorológicas. El sistema permite monitorear en tiempo real las condiciones atmosféricas, analizar tendencias históricas y generar reportes especializados para el desarrollo de proyectos de energías renovables en la provincia de Chimborazo.

Secciones del Sistema

Inicio

Página principal con información del proyecto IDIPI-298, objetivos, instituciones participantes, fotografías y mapas de las estaciones meteorológicas.

Geoportal

Visualización geoespacial de la red de estaciones meteorológicas en un mapa interactivo con marcadores geo-localizados que permiten consultar información detallada de cada estación.

Datos

Consulta y descarga de datos meteorológicos históricos por estación. Permite filtrar por fecha y descargar datasets en formato CSV para análisis externos.

Dashboard

Panel de visualización avanzado con gráficos interactivos de series temporales, distribuciones estadísticas, rosas de viento, climogramas y mapas de calor para análisis detallado de variables meteorológicas.

Tiempo Real

Monitoreo en vivo de las condiciones meteorológicas actuales de todas las estaciones activas, con indicadores visuales y actualización automática de datos.

Mapas

Visualización de mapas temáticos y cartografía especializada de las estaciones meteorológicas, incluyendo mapas de ubicación geográfica y zonificación.

Sensores

Información detallada sobre los componentes, sensores y equipamiento instalado en cada estación meteorológica, incluyendo especificaciones técnicas y estado operativo.

Cómo Visualizar Datos

Dashboard de Visualización
  1. Acceda a la sección Dashboard desde el menú de navegación principal.
  2. Seleccione la estación meteorológica de su interés desde el selector desplegable.
  3. Defina el rango de fechas para el análisis utilizando los selectores de fecha inicial y fecha final.
  4. El sistema generará automáticamente gráficos interactivos con datos de temperatura, humedad, presión, radiación solar y viento.
  5. Utilice las herramientas de zoom, panorámica y selección para analizar períodos específicos.
  6. Descargue gráficos individuales en formato PNG mediante el botón de descarga en cada visualización.
Descarga de Datos
  1. Acceda a la sección Datos desde el menú principal.
  2. Seleccione la estación meteorológica de interés.
  3. Configure el rango de fechas para la extracción de datos.
  4. Haga clic en el botón "Descargar CSV" para obtener el archivo de datos.
  5. El archivo CSV descargado contiene todas las variables meteorológicas registradas en el período seleccionado.
Monitoreo en Tiempo Real
  1. Acceda a la sección Tiempo Real para ver las condiciones meteorológicas actuales.
  2. Visualice tarjetas informativas con los últimos registros de cada estación activa.
  3. Los datos se actualizan automáticamente según la frecuencia de transmisión de cada estación.

Umbrales de Validación de Datos

El sistema implementa un proceso de limpieza y validación automática de datos mediante umbrales técnicos que garantizan la calidad y consistencia de la información meteorológica. Los valores que se encuentren fuera de estos rangos son marcados como NULL durante el procesamiento y no se incluyen en los análisis.

Cómo Cargar Archivos de Datos (Área Administrativa)

Nota: Esta funcionalidad está disponible únicamente para usuarios administradores. Debe iniciar sesión con credenciales de administrador para acceder al módulo de carga de datos.

Formato de Archivo Requerido
  • Formato permitido: Un único archivo CSV (.csv) o TXT (.txt) por carga.
  • Separador de campos: El sistema detecta automáticamente el separador (coma o punto y coma).
  • Estructura del archivo: Debe contener columnas de fecha, hora y variables meteorológicas.
  • Codificación: UTF-8 recomendado para evitar problemas con caracteres especiales.
  • Importante: NO cargue múltiples archivos simultáneamente. El sistema procesa un archivo a la vez.
Niveles de Datos

El sistema maneja diferentes niveles de procesamiento de datos meteorológicos:

  • Nivel L0: Datos crudos sin procesamiento, tal como son registrados por los sensores.
  • Nivel L1: Datos con correcciones básicas y conversión de unidades.
  • Nivel L2: Datos procesados con validación de umbrales, limpieza de valores anómalos y promedios horarios.
Prerequisitos y Orden de Ingreso

IMPORTANTE: El sistema requiere un orden específico al registrar elementos:

  1. 1º - Registrar Estación Meteorológica: Primero debe crear la estación meteorológica con su ubicación, código y datos básicos.
  2. 2º - Registrar Sensores y Componentes: Una vez creada la estación, puede agregar sensores y componentes asociados a ella.
  3. 3º - Cargar Datos: Con la estación registrada, puede comenzar a cargar archivos de datos (L0, L1, L2).
  4. Nota: NO es necesario tener sensores registrados antes de cargar datos. Los sensores son opcionales y sirven para documentar el equipamiento instalado en cada estación.
Proceso de Carga
  1. Inicie sesión con credenciales de administrador haciendo clic en el botón "Administrar" del menú.
  2. Acceda al módulo "Cargar Datos" desde el panel de administración.
  3. Seleccione el nivel de datos adecuado (L0, L1 o L2) según el tipo de archivo que va a cargar.
  4. Seleccione la estación meteorológica correspondiente al archivo de datos.
  5. Arrastre y suelte el archivo CSV/TXT en la zona de carga o haga clic para seleccionarlo desde su equipo.
  6. Verifique que aparezca el nombre del archivo y su tamaño antes de proceder.
  7. Haga clic en "Procesar y Cargar Datos" para iniciar el proceso de validación e importación.
  8. El sistema realizará automáticamente: detección de columnas, validación de umbrales, limpieza de datos y almacenamiento en la base de datos.
  9. Espere la confirmación de carga exitosa con el resumen de registros procesados.

Advertencias Importantes

Carga de Múltiples Archivos: El sistema NO admite la carga simultánea de múltiples archivos. Debe cargar y procesar un archivo a la vez. Espere a que finalice el procesamiento antes de cargar el siguiente archivo.

Validación de Datos: Los valores que excedan los umbrales establecidos serán automáticamente marcados como NULL y no se incluirán en las visualizaciones ni análisis. Verifique la calidad de sus datos antes de la carga.

Archivo Único por Carga: Para mantener la integridad de los datos y facilitar la trazabilidad, cada carga debe corresponder a un único archivo CSV o TXT con datos coherentes de una sola estación.
