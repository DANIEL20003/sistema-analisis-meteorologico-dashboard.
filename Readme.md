Sistema de Analisis y Dashboard Meteorologico
Descripcion del Proyecto
Este repositorio contiene el codigo fuente y la configuracion de un sistema integral diseñado para la gestion, procesamiento y visualizacion de datos climaticos. El proyecto fue desarrollado en el marco de las Practicas Preprofesionales en la Escuela Superior Politecnica de Chimborazo (ESPOCH).

El objetivo principal es centralizar la informacion capturada por estaciones meteorologicas para facilitar el analisis tecnico y la generacion de reportes mediante un entorno web escalable.

Caracteristicas Tecnicas
Arquitectura de Software: Implementacion basada en el patron de diseño Modelo-Vista-Controlador (MVC) para asegurar la separacion de responsabilidades.

Procesamiento de Datos: Gestion de variables meteorologicas y almacenamiento en bases de datos relacionales.

Entorno de Servidor: Configuracion y despliegue en servidores Linux (Ubuntu) utilizando stacks LEMP (Linux, Nginx, MySQL, PHP) o LAMP (Linux, Apache, MySQL, PHP).

Seguridad: Uso de archivos de configuracion protegidos y exclusion de datos sensibles mediante politicas de versionamiento.

Especificaciones del Stack
Sistema Operativo: Ubuntu Server.

Lenguaje de Programacion: PHP.

Gestor de Base de Datos: MariaDB / MySQL.

Herramientas de Control de Versiones: Git y GitHub.

Estructura del Repositorio
config/: Contiene los parametros de conexion a la base de datos y variables de entorno.

controller/: Contiene la logica de control que gestiona la comunicacion entre los modelos y las vistas.

model/: Contiene la definicion de las estructuras de datos y las consultas a la base de datos.

views/: Contiene la interfaz de usuario y los componentes del dashboard de visualizacion.
